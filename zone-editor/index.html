How to use this layout

Save the JSON into the project's configs folder. Set STORE_LAYOUT_PATH to that file, PIPELINE_VIDEO_SOURCE to your original video, and PIPELINE_STORE_ID to the Store ID above before running the pipeline.

Use one layout per fixed camera view. If the camera moves, zooms, or changes resolution, recalibrate. Draw the doorway across the tracked person's centre path: the current pipeline uses box centres.
